# Рассуждение о дизайне ориентированные на данные

СУЩНОСТЬ определяется уникальным идентификатором в рамках заданного контекста выполнения.
КОМПОНЕНТ есть ДАННЫЕ не связанные ЛОГИКОЙ.
СУЩНОСТИ можно задать бесконечное множество КОМПОНЕНТОВ.

СУЩНОСТЬ - есть не конечный ТИП, а множество КОМПОНЕНТОВ определяющий ее.

КОНТЕКСТ выполнения владеет СУЩНОСТЯМИ, данными КОМПОНЕНТОВ, и знанием
какие КОМПОНЕНТЫ соответствуют заданным СУЩНОСТЯМ, а пользовательскому коду
предоставляет по требованию ПРОКСИ обертки над подмножеством компонентов
СУЩНОСТИ.
Так, например, если СУЩНОСТЬ с ID содержит компоненты: [Mesh, Translation2d,
Rotation, Material, Serializable], а пользовательский код должен
реализовать логику отображения СУЩНОСТИ он просит у контекста ПРОКСИ
IDrawable данной СУЩНОСТИ, которая есть обертка над компонентами
[Translation, Rotation, Material, Mesh], и может предоставлять методы чтения
задания значений данных компонентов.

Пример использования:

```cpp
// ...

Context ctx {};

auto entity         = ctx.create<primitive::Point>(2.0, 4.0);
auto maybe_drawable = ctx.try_as<interface::IDrawable>(entity);

if (maybe_drawable)
{
    auto &drawable = maybe_drawable.value();

    renderer.draw_vertices(drawable.translation(), drawable.mesh(), drawable.material(), POINTS);
}
```

в примере выше, `primitive::Point` определяет КАТЕГОРИЮ сущностей (не является КОМПОНЕНТОМ).
Контекст создаст сущность с новым ID и задаст ей компоненты: [Mesh, Translation2d {2.0, 4.0}, Material, Serializable],
потому что данные КОМПОНЕНТЫ определяют `primitive::Point`.

далее `ctx.try_as<interface::IDrawable>(entity)` создаст из переданной сущности ПРОКСИ IDrawable,
которая есть тонка обертка над КОМПОНЕНТАМИ [Mesh, Translation2d, Material]. ПРОКСИ пригодна для использования в ЛОГИКЕ программы.

`try_as` возвращает `optional`, потому как достоверно не может быть известно в пользовательском коде, содержит ли СУЩНОСТЬ необходимые КОМПОНЕНТЫ.

Допустимо попросить контекст сформировать множество всех IDrawable, отсортированных в порядке отрисовки.

```cpp
// ...

for (auto drawable : ctx.all_as<interface::IDrawable>())
{
    draw_controller.draw(renderer, drawable);
}
```
